# Set colData

Set colData of dreamletProcessedData, and check for same dimensions and
rownames

## Usage

``` r
# S4 method for class 'dreamletProcessedData,ANY'
colData(x, ...) <- value
```

## Arguments

- x:

  `dreamletProcessedData` object

- ...:

  other arguments

- value:

  `data.frame` or object that can be coerced to it

## Value

none
